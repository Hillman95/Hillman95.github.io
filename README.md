# Portfolio — Аднан Байбатыров

Светлый one-page сайт-портфолио mobile-разработчика.

## Стек

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Сборка

```bash
npm run build
npm start
```

## Контент

Основные блоки:

- Hero с акцентом на mobile-разработку
- Проекты: ЦПУ (билайн), ЛяРиба, Dirham, WeCompete
- Опыт: билайн / VK / Tooba
- Обо мне + блок про LLM / AI Agents / MCP
- Контакты
